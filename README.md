# Pack productivity — вебзастосунок

Програма завантажує `Pack data` та `Employees`, рахує один рядок як один
виконаний бокс і створює погодинний звіт.

## Що показує звіт

- станція (сортування за номером);
- ім’я та ID працівника;
- індивідуальна погодинна норма;
- загальна кількість боксів;
- кількість і відсоток норми за кожну годину;
- червоний, жовтий або зелений колір у відсоткових клітинках.

Норми: 140 для стажу 0–6 днів, 180 для 7–13 днів, 220 для 14–20 днів і
260 від 21 дня. Якщо ID немає у файлі Employees, застосовується норма 260.

## Запуск на Windows або Mac

1. Встановіть Python 3.11 або новіший.
2. Розпакуйте архів і відкрийте термінал у папці `pack_web_app`.
3. Встановіть бібліотеки:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустіть програму:

   ```bash
   streamlit run app.py
   ```

5. Браузер відкриє локальну адресу програми.

Для використання з iPad застосунок потрібно розмістити на сервері. Тоді він
відкриватиметься як звичайний сайт через браузер.

## Потрібні колонки

Pack data: `Operator`, `Packing station`, `Operation time`.

Employees: `Employee ID`, `Create time`.

Програма автоматично шукає аркуш, у якому є ці колонки.
