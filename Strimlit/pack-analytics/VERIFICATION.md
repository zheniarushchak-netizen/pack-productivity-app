# Перевірка перенесення

Дата: 2026-10-14.

Перевірено локально на Python 3.14, Streamlit 1.50.0, pandas 2.3.3, openpyxl 3.1.5. Для розгортання рекомендовано Python 3.12; GitHub Actions налаштовано на цю версію.

- 4 сценарії порівняння з оригінальним скриптом: денний, нічний, продовжений денний, продовжений нічний — пройдено.
- У кожному сценарії збігаються всі 8 експортованих таблиць і додаткова таблиця станцій, включно з типами даних та індексами.
- У кожному сценарії збігаються значення та стилі клітинок усіх 4 Excel-аркушів.
- AST-перевірка обчислювальних операторів та функцій get_status/find_break/cal_rate — пройдено.
- Перевірка некоректного Excel та відсутніх колонок — пройдено.
- Streamlit AppTest: усі 9 таблиць, 4 KPI, перемикачі нічної/продовженої зміни, стан без завантажених файлів — пройдено.
- Локальний сайт відкрито в браузері: перевірено оформлення головної сторінки, графік, KPI та наявність таблиць.

Разом: 7 успішних тестів. Під час першого запуску виявлено несумісність допоміжної бібліотеки графіків із локальним Python 3.14; візуалізацію переведено на вбудований Vega-Lite API Streamlit, після чого UI-тест пройшов. Обчислювальний код при цьому не змінювався.

Середовище видає попередження NumPy про майбутню зміну обробки timedelta; вони також виникають при запуску оригіналу та не спричиняють розбіжностей у тестах.

Реальні вхідні файли користувача не надано. Тести не доводять коректність початкових бізнес-формул для всіх можливих даних; вони перевіряють збереження початкової поведінки. Публікацію на GitHub/Streamlit Cloud не виконано: передається готовий до завантаження проєкт.
